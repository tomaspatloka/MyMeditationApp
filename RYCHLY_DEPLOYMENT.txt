┌──────────────────────────────────────────────────────────────┐
│ KROK 1: Registrace Cloudflare                               │
└──────────────────────────────────────────────────────────────┘

   1. Otevřete: https://dash.cloudflare.com/sign-up
   2. Vyplňte email a heslo
   3. Ověřte email (klikněte na link)
   4. Přihlaste se: https://dash.cloudflare.com/login


┌──────────────────────────────────────────────────────────────┐
│ KROK 2: Otevřete Pages                                      │
└──────────────────────────────────────────────────────────────┘

   1. Levé menu → "Workers & Pages"
   2. Klikněte "Create application"
   3. Záložka "Pages"
   4. Tlačítko "Connect to Git"


┌──────────────────────────────────────────────────────────────┐
│ KROK 3: Připojte GitHub                                     │
└──────────────────────────────────────────────────────────────┘

   1. Klikněte na GitHub logo
   2. "Authorize Cloudflare Pages"
   3. "Install & Authorize"
   4. Vyberte "MyMeditationApp" repozitář
   5. Klikněte "Install"


┌──────────────────────────────────────────────────────────────┐
│ KROK 4: Konfigurace projektu                                │
└──────────────────────────────────────────────────────────────┘

   Vyplňte:

   Project name:         mymeditationapp
   Production branch:    main
   Build command:        (PRÁZDNÉ - nic nevyplňujte!)
   Build output:         /

   ⚠️  DŮLEŽITÉ: Build command nechte PRÁZDNÝ!


┌──────────────────────────────────────────────────────────────┐
│ KROK 5: Deploy!                                             │
└──────────────────────────────────────────────────────────────┘

   1. Klikněte "Save and Deploy"
   2. Počkejte 2-3 minuty
   3. Hotovo! 🎉
